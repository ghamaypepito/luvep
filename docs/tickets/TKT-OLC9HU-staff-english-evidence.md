# TKT-OLC9HU — Staff Resident English evidence record

The approved scope is the Resident intake's English Language Evidence field only. Immigration managers, Immigration advisers and existing administrators can record **Not Required** with a reason. This records a staff choice; it does not decide exemption eligibility, approve a visa, or waive any document checklist.

In Immigration → Assessments, open a Resident submission, edit **English & Family**, select **Not Required**, enter the reason, and save. The same shared assessment workspace is used when opening the intake from a case's VIF. English evidence history shows previous choices, reasons, actors and timestamps. Repeating an unchanged save does not create a new decision. Returning to a normal evidence choice removes the active reason while retaining history.

The Resident intake owns one nullable JSON column, `english_evidence_exception`, for the current reason and attribution. Each changed staff evidence record writes a complete before/after entry to the existing activity log in the same database transaction. Existing intake values remain unchanged by the migration. Its down migration removes the new column; retain the database backup and activity log when rolling back after use.

Applicant forms do not offer Not Required. New submissions, edit-link requests and the authenticated client assessment editor reject forged values and staff metadata. An applicant editing an intake that already has this staff record sees it read-only. Their other changes and appended files remain available; a locked fresh read in both applicant update paths prevents a stale form from overwriting the staff choice. Private reasons and staff attribution are omitted from public edit data and external AI review payloads. Recreating an assessment does not copy the original intake's staff evidence decision.

Writer audit: the public Resident controller creates and updates Resident intakes; the shared staff inline editor records the reason; the authenticated lead portal updates allowlisted assessment fields; IntakeTypeConverter creates a new intake with reset staff evidence.
