# TKT-DZXD4L - Education cost breakdown and indicative currency conversion

Adds an Education-only Breakdown Cost tab beside Agreements. Existing proposals, consultancy agreements, signatures, amounts and the older Philippine breakdown download stay unchanged.

Confirmed scope: current residence defaults to Philippines / NZ onshore / other countries offshore, with staff override. Single, Couple and Couple with child are supported. Staff enter descriptions and original amounts (up to 30 items); no unapproved country/family prices are inferred. Original currency stays explicit. Blank/unrecognized residence requires staff review; currency defaults use a static ICU-derived mapping for the existing country catalogue, with manual override for ambiguous/new currencies.

Automatic indicative conversion uses Frankfurter v2 reference rates: https://frankfurter.dev/javascript/ . Only currency codes go to its fixed HTTPS endpoint, never client identities or amounts. Rates cache 30 minutes, have a dated freshness check (maximum 7 days for publication gaps), and are shown with source/date. Malformed, nonpositive, future or stale rates fail visibly. No guessed/stale fallback. Requests time out; existing document generation has no dependency on the provider.

An encrypted one-hour quote snapshot binds the selected currencies and rates. Preview, PDF download and saving use that same snapshot, not browser-supplied converted amounts. Rows are converted from their original currency into NZD/local estimates; totals sum rounded line amounts using two decimals. This is indicative reference material, not an invoice, payment demand or repricing of an existing agreement.

Each explicit Save new breakdown creates a private LeadDocument with its own PDF and rate/amount snapshot. No replacement/edit API, mail send or migration is introduced. Latest 50 saved documents are listed; the existing authorized download flow is reused. Client selection is searchable (50 matching results) and restricted to accessible Education leads/students, excluding pure Immigration-only records. Switching client clears unsaved costs to prevent mixing records. Failed storage/database saves clean up the newly created file.

Verification: actual Education page interaction test (Sales tab isolation, defaults, overrides, family, editable rows, conversions, preview/save, expired-rate errors and retry); EducationCostBreakdownTest (provider mock isolation, preview/download/save snapshots, totals, multiple families and countries, long PDF, XSS escaping, validation, tampered/expired rates, denied access); existing PDF/issued agreement and agreement UI tests. Provider NZD/PHP endpoint separately checked using currency codes only. Synthetic short and 30-row PDF artifacts rendered for layout review. Full PR build/regression CI required before review handover.

Deployment: no schema migration or API key. Outbound HTTPS access to api.frankfurter.dev is needed for this new builder's conversion only. No live client documents or records were modified.
