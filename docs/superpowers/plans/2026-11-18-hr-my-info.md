# HR My Info Implementation Plan

> Use superpowers:subagent-driven-development with independent whole-change review before merge.

**Goal:** Add the requested personal profile, uploads, employment text and equipment options to the deployed HR Portal.
**Architecture:** Extend existing HR models/controllers/services and add a shared My Info tab strip. Keep existing class-specific access and private storage; additive employee/policy/equipment fields only.
**Tech Stack:** Laravel, Inertia React, existing private filesystem and ZipArchive, Vite.
**Spec:** docs/superpowers/specs/2026-11-18-hr-my-info.md

## Global Constraints
HR only; no permission grants, production test records, outward messages or finance writes. Staff access is owner-only. Preserve policy immutability, document revocation/classification, staff preview read-only, employee version guards and custody audit. Taste Vault queried for employee profile/documents/settings HR: no match; reuse approved HR visual system.
