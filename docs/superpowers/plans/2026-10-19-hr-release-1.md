# Luvep HR Release 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Ship the employee/HR shell, protected profiles, SSO, read-only admin preview, live attendance, leave and Manager/Admin notifications.
**Architecture:** New focused HR controllers/services reuse User, DtrSetting, DtrEntry, DtrLeave and the existing notification inbox. Additive HR tables hold enrollment, live time events, review state and notification delivery records.
**Tech Stack:** Existing Laravel 12 / React 19 / Inertia stack, PHP 8.3, SQLite tests and MySQL deployment checks.
**Spec:** [Approved design](../specs/2026-10-19-hr-portal-design.md)

## Global Constraints

All constraints and the notification contract in [the master plan](2026-10-19-hr-implementation.md) apply. Main production release remains disabled until staging verification and roster setup pass.

## Review Focus

Cookie migration (task 3), cross-user/preview access (tasks 1–2), concurrent and DST timekeeping (task 4), legacy autosave compatibility (task 5), repeated decisions and deliveries (tasks 6–7).
