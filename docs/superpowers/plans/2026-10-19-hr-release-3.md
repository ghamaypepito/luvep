# Luvep HR Release 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Complete onboarding/exits, equipment tracking, milestones, scoped reports and access/audit administration.
**Architecture:** Build operational modules on the approved employee/access/audit/event foundation. Queued exports reauthorize at creation, processing and download; checklist completion never implicitly alters account permissions.
**Tech Stack:** Existing Laravel 12 / React 19 / Inertia 2, PHP 8.3, private storage, Redis queues and scheduler.
**Spec:** [Approved design](../specs/2026-10-19-hr-portal-design.md)

## Global Constraints

- All [master-plan constraints](2026-10-19-hr-implementation.md) and notification rules apply.
- Employees see their own authorized records; confidential files default private. Admin employee preview is read-only and audited.
- No automatic pay calculation, statutory accrual, destructive account deletion or implicit offboarding access removal.
- Reports use verified stored records; empty data never becomes invented employee metrics or leave balances.

## Review Focus

- Template edits must not silently change active onboarding/exit checklists: task 1.
- Scheduled overdue notices must survive retries without repeated application-level deliveries: task 2.
- Permissions revoked while an export waits or downloads must revoke the artifact too: task 3.
- CSV formula content in employee-provided text must be neutralized: task 3.
- Ordinary Admin self-elevation or revocation of the last access administrator must fail: task 4.
