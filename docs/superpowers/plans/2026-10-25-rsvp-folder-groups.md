# Manual attendance folder groups

Extend existing Education shared folders with manually selected RSVP membership. User requests an option to add registrants to folder groups from the attendance manager. Select one or several visible entries, select an existing folder and Add to group. Selection is explicitly current page. A record may belong to several groups; repeated adds are idempotent. Folder groups can be opened, combined with existing filters, saved as dynamic filter lists and exported through existing CSV/PDF query. Existing saved filter lists remain automatic and do not themselves add manual memberships. Remove from group detaches only that relation, preserving RSVP, pipeline and journey.

Add one scoped pivot migration with unique folder/RSVP pair, creator and timestamps. Role/CSRF protections match attendance. Validate entire batch before atomic write; lock folder and selected entries and preserve original added_by on repeated add. Audit IDs/counts only, no notifications. UI: folder filter, grouped count/open links within library, row checkboxes, select-page and compact Add to group form, memberships shown per row and Remove from group when viewing a group. Reuse existing light/dark styling. No new dependency, broad portal redesign, attendee duplication or lead creation.
