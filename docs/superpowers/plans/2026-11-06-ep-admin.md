# Ep Admin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans task-by-task.

**Goal:** Replace the local Admin concept with a live metadata-only Ep monitoring dashboard.
**Architecture:** Read-only reporting service on existing runs/ledger/accounts, new gated admin endpoints, React/Inertia page with native details dialog and hash tabs. Reuse existing connector administration.
**Tech Stack:** Laravel12/PHP8.3, React19/Inertia, existing CSS/Lucide; no packages or migrations.
**Spec:** `docs/superpowers/specs/2026-11-06-ep-admin-design.md` and `docs/ep-agent/readiness.md`.

## Global Constraints

Keep current admins-only pilot. Paid=false and no provider calls. No credential/budget/workflow writes. No private transcript/title/body/idempotency/system-instruction exposure. No raw connector secrets or failures. Budgets remain unconfigured unless actually provisioned; costs are USD micro-dollar strings and null per-run costs remain unknown. Preserve existing staff assistant, Manager, connectors and business records.

## Review Focus

- Cross-user private content must never appear in list/detail, even for Super Admins.
- Null, uncertain and orphan usage must remain distinct from recorded zero charges.
- Multiple/expired/frozen budget accounts must not imply a single spendable team cap.
- Filter/hash/refresh races and permission revocation must clear stale metadata/details.
- Existing connector configuration must not be represented as an active Ep transport or exposed to plain admins.

### Task 1: Read-only admin reporting

Files: `app/EpAgent/AdminOverview.php`, `app/Http/Controllers/Admin/EpAgentOverviewController.php`, `routes/ep-agent.php`, `tests/Feature/EpAgent/AdminOverviewTest.php`.
Interfaces: fresh `authorize(User)` requires Pilot and admin; `overview(User,period):array`, `runs(User,period,portal,state,before):array` returns25rows+cursor, `run(User,id):array`. Period values month/7d/30d are server UTC creation windows. Task filters are validated/mapped. Runs expose id/actor work-name/portal/safe-state/reason label/timestamps and allowlisted metering only. Overview includes global-window run counts, ledger recorded cost and usage, all-date open holds, unresolved/unattributed counts, and up to20individually described budget accounts. Money serialized decimal micro-USD strings, not floats. Connector summary for Super Admin only; no transport/credential test.
