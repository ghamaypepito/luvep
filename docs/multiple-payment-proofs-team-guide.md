# Multiple proofs of payment — team guide

Ticket: TKT-WEILQE. Existing page structure, navigation and theme are retained.

## Who changes a payment-proof status?

Active Finance, Admin and Super Admin users can confirm a proof or mark it Needs attention. Immigration staff with existing case access can view evidence; financial decisions must use the Finance review. Generic document approval does not confirm payments.

## Client steps

1. Open the existing engagement/invoice link from the ePortal.
2. Find the matching invoice and choose **Upload proofs of payment**.
3. Select one or more PDF, JPG, JPEG, PNG, WebP or GIF files: up to 10 files per upload, up to 10 MB each.
4. Wait for the files to appear individually as **Under review**. Upload more later when needed; earlier files remain available.
5. Check each file's result: **Confirmed** or **Needs attention**. Read the reason and upload a clearer or corrected file when requested. Prior evidence remains retained.
6. The invoice shows confirmed money and the remaining balance. Uploading a file does not itself confirm a payment.

## Finance / Admin steps

1. Open **Finance → Invoice → Proof of payment**.
2. Find the client and the specific file. Click its eye / **View & verify** action. Users who also have case access can open **Verify payment** on an unpaid invoice, or **Review payment / Confirmed — view review** on an individual proof in the case's Documents tab.
3. View/download the file and check the invoice and currency. If an older invoice has no saved currency, select its actual currency from the invoice before confirming.
4. For a separate bank transfer, keep **Record a separate payment** and enter the actual amount received, payment date, and the transfer's unique bank transaction ID. Use the bank transaction ID even if several transfers repeat the invoice number.
5. If another file supports money already recorded, choose **Supporting file for an existing payment**, then select the matching receipt. This confirms the evidence without adding the money again. An unallocated manual/installment receipt can be linked only to the matching case, invoice and currency.
6. Click **Confirm payment**. Only this file is confirmed. The reviewer and review date are retained.
7. If the evidence cannot be accepted, click **Needs attention**, enter a clear reason, then **Save needs attention**. Other files and previously confirmed money are unchanged.
8. Repeat for the remaining files. An invoice becomes paid only when its distinct confirmed receipts cover its total. A partial payment does not settle another invoice or advance the case prematurely.

## Example

For a NZD 1,200 invoice: confirm a NZD 400 transfer; NZD 800 remains. Link a second file for that same transfer as supporting evidence; NZD 800 still remains. Confirm a different NZD 800 transfer; the invoice is paid. Three files, two payments, NZD 1,200 counted once.

## Reference and corrections

All uploaded proofs stay in the payment record/case documents. Confirmed proofs and their linked receipts cannot be removed or rewritten through these actions. Escalate a confirmed-payment correction to Finance. Currency conversion and refund/correction journals are outside this feature. Historical approvals remain historical; the update does not invent receipt amounts or backfill old transactions. Older evidence without an invoice association requires Finance to choose the matching invoice during review.
